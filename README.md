# Painel do Clima

Projeto full stack atualmente vazio, criado como base para a implementação de novas funcionalidades. O objetivo é construir um painel de monitoramento climático com separação clara entre frontend e backend.

## Stack

**Frontend**
- React 19
- Vite

**Backend**
- Node.js
- Express

## Estrutura

```
.
├── frontend/   # Aplicação React
└── backend/    # API Node.js com Express
```
